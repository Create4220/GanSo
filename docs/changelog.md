# 更新记录

## 1.2.0

- 常显时间块移至人物头顶，正式 GanSo 标题显示在任务名称前。
- 改为默认宽 440 像素的单列布局，减少桌面横向占用。
- 展开界面底部显示“全员”类当前形象的名字，换图时同步更新。
- 控制区从时间块下方向下展开，遮挡重叠人物；人物与时间块都不被挤走。收起后恢复完整人物。
- 保留两区域拖动、人物按压复原、正计时/倒计时和三遍完成提示音。
- 65 项检查通过，包含标题位置、展开遮挡、人物恢复和全员类名字对应检查。

## 1.1.0

- 修复未勾选随机提示时，完成提示音只播放一次的问题。现在两种计时模式正常完成均完整播放三次 Codex 提示音。
- 任务名称、数字时间、进度条和人物常显，其他控件默认收起，点击常显任务/时间区展开或收起。
- 人物与常显区都可拖动；移动超过阈值后不触发展开。
- 点击人物只显示固定透明度的临时变暗蒙层，不开关窗格。松开、鼠标捕获丢失、窗口失焦后恢复，避免反复点击产生亮度偏差。
- 玻璃材质跟随控制区尺寸变化，常显区展开时保持位置。
- 53 项检查通过；实际音频通路验证三次完整播放，总时长约 2.09 秒。

## 1.0.0

首个公开版本，提供角色陪伴、正计时/倒计时、任务清单、累计专注和可选随机休息提示。
